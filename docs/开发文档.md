# 开发文档

## 架构概览

```
main.py          入口，创建 Tk 根窗口并初始化 CleanerApp
  └── gui.py         CleanerApp — 所有 UI 逻辑，通过线程调用 cleaner
        └── cleaner.py  DiskCleaner — 平台无关的扫描/清理核心
              └── config.py  Config — JSON 持久化配置
```

### 线程模型

所有 I/O 密集型操作（扫描、清理）在后台 `daemon` 线程中执行，通过 `root.after(0, callback, ...)` 将结果回调到主线程，保证 Tkinter 的单线程安全。

## 核心模块

### `cleaner.py`

#### `format_bytes(size: int) -> str`
将字节数转换为人类可读字符串（B / KB / MB / GB）。

#### `get_dir_size(path: str) -> (int, int)`
递归统计目录总大小（字节）和文件数量。忽略无权访问的文件。

#### `get_disk_usage(drive: str) -> (total, used, free)`
封装 `shutil.disk_usage`，返回三元组（字节）。

#### `is_admin() -> bool`
调用 `ctypes.windll.shell32.IsUserAnAdmin()` 检测管理员权限。

#### `CleanItem`
```python
@dataclass
class CleanItem:
    path: str       # 绝对路径
    size: int       # 字节数（扫描时统计）
    is_dir: bool    # True = 清理目录内容；False = 删除单个文件
```

#### `CleanCategory`
```python
@dataclass
class CleanCategory:
    id: str             # 唯一标识符
    name: str           # 显示名称（中文）
    description: str    # 说明文字
    items: List[CleanItem]
    total_size: int     # 所有 items 的总字节数
    file_count: int     # 所有 items 的总文件数
    enabled: bool       # True = 可直接清理；False = 仅分析
    error: str          # 扫描时捕获到的异常信息
```

#### `DiskCleaner`

| 方法 | 说明 |
|---|---|
| `scan(on_progress)` | 扫描所有类别，返回 `List[CleanCategory]` |
| `clean(category_ids, on_progress, on_log)` | 清理指定类别，返回 `(bytes_freed, files_removed)` |
| `_add_dir(cat, path)` | 将一个目录加入类别（支持 `%ENV%` 展开） |
| `_add_file(cat, path)` | 将单个文件加入类别 |
| `_clean_dir_contents(path, on_log)` | 删除目录内所有文件和子目录（保留目录本身） |

**扫描流程：**
1. 按 `CATEGORIES` 顺序逐个调用对应私有方法（`_scan_*`）
2. 每个方法调用 `_add_dir` / `_add_file` 填充 `CleanCategory`
3. 通过 `on_progress(value: float, status: str)` 回调更新进度

**清理流程：**
1. 过滤出 `total_size > 0` 的目标类别
2. 回收站单独使用 `SHEmptyRecycleBinW` Win32 API
3. `hiberfil` 使用 `powercfg /h off` 关闭休眠
4. 其余目录调用 `_clean_dir_contents`（保留根目录）
5. 单文件直接 `os.remove`

### `gui.py`

#### `CleanerApp`

| 属性 | 类型 | 说明 |
|---|---|---|
| `cleaner` | `DiskCleaner` | 核心逻辑实例 |
| `_checked` | `Dict[str, bool]` | 每个 `cat.id` 对应的勾选状态 |
| `_scanning` | `bool` | 扫描中标志，防止并发 |
| `_cleaning` | `bool` | 清理中标志，防止并发 |

**UI 构建方法：**
- `_build_header()` — 蓝色标题栏
- `_build_disk_info()` — 磁盘空间三列 + 进度条
- `_build_category_list()` — `ttk.Treeview` + 全选复选框 + 总大小标签
- `_build_buttons()` — 扫描 / 清理按钮 + 状态文本
- `_build_progress()` — 操作进度条
- `_build_log()` — 带颜色标签的 `ScrolledText`

**Treeview 勾选实现：**
Tkinter 原生 `Treeview` 不支持内嵌复选框，本工具通过以下方式模拟：
1. 在行文本前添加 `☑` / `☐` Unicode 符号
2. `<ButtonRelease-1>` 事件切换 `_checked[row_id]` 并更新行文本和 tag
3. `tag_configure` 将未选中行文字变灰，提供视觉反馈

  "excluded_paths": []

## 扩展指南

### 添加新的清理类别

1. 在 `DiskCleaner.CATEGORIES` 列表中添加一个三元组：
   ```python
   ("new_id", "显示名称", "说明文字"),
   ```

2. 在 `DiskCleaner.scan()` 的 `scanners` 字典中注册扫描函数：
   ```python
   "new_id": self._scan_new_category,
   ```

3. 实现扫描方法：
   ```python
   def _scan_new_category(self, cat: CleanCategory) -> None:
       self._add_dir(cat, r"C:\Some\Path")
       self._add_file(cat, r"%LOCALAPPDATA%\Some\file.log")
   ```

清理逻辑会自动处理新类别，无需额外代码（除非需要特殊清理方式，如回收站那样使用 Win32 API）。
如果新类别只是做空间分析，不应直接删除，请把 `enabled` 设为 `False`。

### 添加特殊清理逻辑

在 `DiskCleaner._clean_category()` 中添加 `if cat.id == "new_id":` 分支，编写自定义清理代码。

## 已知限制

- 仅支持 Windows 操作系统（依赖 `ctypes.windll`、`SHEmptyRecycleBinW`）
- 浏览器缓存路径针对默认安装位置；用户自定义安装路径不被检测
- 系统目录（`C:\Windows\Temp` 等）需要管理员权限
- 扫描大量文件时（如 `%TEMP%` 包含数万文件）可能耗时数秒
- `WinSxS`、`pagefile.sys` 等项目仅做分析，不直接删除
