# 使用说明

## 启动程序

### EXE 版本
```
双击 dist\C盘清理工具.exe
```
该 EXE 会在启动时请求管理员权限。

### 源码版本
```
双击 run.bat
```
`run.bat` 会自动请求管理员权限后启动程序。

管理员模式可清理以下目录：
- `C:\Windows\Temp`
- `C:\Windows\SoftwareDistribution\Download`（Windows 更新缓存）
- `C:\Windows.old`（若存在）
- `C:\Windows\Prefetch`（预读取缓存）
- `C:\Windows\Logs`
- `C:\hiberfil.sys`（通过关闭休眠释放）

以下项目会显示为“仅分析”，不会直接删除：
- `C:\pagefile.sys` / `C:\swapfile.sys`
- `C:\Windows\WinSxS`

后续修改代码后，可双击 `build_exe.bat` 重新打包 EXE。

## 操作步骤

### 第一步：扫描

点击界面中的 **"🔍 开始扫描"** 按钮，程序会自动检测以下位置的可清理文件，并在列表中显示每类的**大小**与**文件数量**。

扫描完成后，底部操作日志会显示：
```
✓ 扫描完成，共找到可清理空间: 2.34 GB
```

### 第二步：选择清理项目

扫描结果以列表形式展示，每行代表一个清理类别：

| 图标 | 含义 |
|---|---|
| ☑ | 已选中，将参与清理 |
| ☐ | 未选中，跳过该类别 |
| - | 仅分析项目，不可选中，不会直接清理 |

**操作方式：**
- **点击可清理项目行**：切换该类别的选中/未选中状态
- **顶部"全选/全不选"复选框**：一键选中或取消所有可清理类别
- 右上角实时显示**当前选中项目的总可清理空间**

### 第三步：执行清理

确认选中项目后，点击 **"🗑 清理选中"** 按钮：

1. 弹出确认对话框，显示将清理的类别数量和预计释放空间
2. 点击"是"开始清理，"否"取消操作
3. 进度条实时更新清理进度
4. 底部日志滚动显示每个被删除文件的详情
5. 清理完成后自动重新扫描，更新磁盘信息

## 界面说明

### 磁盘信息区域

| 字段 | 说明 |
|---|---|
| 总容量 | C: 盘的总磁盘空间 |
| 已使用 | 当前已用空间 |
| 可用空间 | 当前剩余可用空间 |
| 使用率进度条 | 绿色 ≤75%，橙色 75–90%，红色 >90% |

点击 **"刷新"** 按钮可手动更新磁盘信息（清理后自动刷新）。

### 操作日志颜色说明

| 颜色 | 含义 |
|---|---|
| 蓝色 | 普通信息（扫描进度等） |
| 绿色 | 成功操作（[OK]） |
| 橙色 | 跳过文件（[跳过]，通常因文件被占用） |
| 红色 | 错误或权限不足（[错误] / [权限]） |

## 常见问题

### Q: 为什么有些项目大小显示为 0 B？
某些目录在当前系统上不存在（例如未安装 Firefox），或已经是空的，显示为 0 B 属正常情况，清理时会自动跳过。

### Q: 清理后程序首次启动变慢了？
这是清理**预读取缓存**（Prefetch）的正常现象。Windows 会在下次运行时重新建立预读取缓存，之后启动速度恢复正常。

### Q: 休眠文件能删吗？
可以，但不是直接删除文件，而是通过关闭休眠实现。程序会调用 `powercfg /h off`，这会同时关闭休眠和快速启动。

### Q: 提示"[权限] 无法访问 ..."？
少量系统目录即使管理员模式也可能被系统服务占用或保护，程序会自动跳过这些文件。

### Q: 清理后能恢复吗？
**不能恢复。** 清理的文件直接删除，不经过回收站。请在清理前仔细确认选中的项目。

### Q: 浏览器缓存清理后影响正常使用吗？
不影响。浏览器缓存只是加速网页加载的临时数据，清理后浏览器会在访问网页时自动重建缓存，网页功能不受影响（首次加载可能稍慢）。

### Q: 支持清理其他磁盘（D:、E:）吗？
当前版本主要针对 C 盘系统目录。回收站清理会覆盖所有驱动器的回收站。

## 安全说明

本工具仅清理以下类型的数据，**不会**触碰个人文档、应用程序本体或系统核心文件：

- 临时文件（`.tmp`、`~` 开头文件等）
- 浏览器缓存（非书签、密码、历史记录）
- Windows 自动生成的日志与报告
- 已下载完毕的系统更新安装包
